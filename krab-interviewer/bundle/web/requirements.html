Driver requirements

Please confirm you meet each item below. Supervisors review every application and follow up on Telegram.

  • 🪪
    Valid driver’s license Current license in good standing; you’ll enter the number and upload a photo.
  • 📱
    Reliable smartphone Phone and email we can use for interview scheduling and onboarding.
  • 💬
    Telegram with public @username All hire communication runs through Telegram. Install & set username →
  • ⏳
    Work commitment Honest availability (hours per week, days, schedule) for dispatch planning.
  • 🏠
    Mailing address Used for paperwork and shipments after you’re hired (e.g. lead materials).
  • 💰
    Payment method on file CashApp, Venmo, Zelle, or similar — listed on your application.
  • 🚨
    Emergency contact Name and phone number of someone we can reach if needed.
  • ✨
    Professional conduct One application per person; accurate information; duplicate Telegram usernames are rejected.
