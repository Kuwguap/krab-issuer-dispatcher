Attach this hiring funnel to your project

Use path /interview for the application form only, or embed the full funnel from /. API calls always go to KRAB_API_BASE_URL in static/config.js.

URLs on this service

PathUse case
/Full funnel landing (hero, steps, CTA)
/requirementsRequirements checklist before apply
/interviewApplication form only — best for embeds
/how-to-telegramTelegram install + @username guide
/interview/embedThis documentation page

Option A — Form only (recommended for other sites)

Embed just the application under /interview. Users should still link to requirements and Telegram setup from your site.

<iframe src="BASE_URL/interview" width="100%" height="920" style="border:0;border-radius:12px" title="Driver application" ></iframe>

Option B — Full hiring funnel

Embed the landing page; drivers click through requirements → form on your iframe.

<iframe src="BASE_URL/" width="100%" height="900" style="border:0;border-radius:12px" title="Become a driver" ></iframe>

Option C — Custom subdomain (CNAME)

Point apply.yourdomain.com → your Render host (e.g. krab-interviewer-bot.onrender.com), then use relative paths:

https://apply.yourdomain.com/interview https://apply.yourdomain.com/requirements

Option D — Link out (no iframe)

<a href="BASE_URL/requirements">Driver requirements</a> <a href="BASE_URL/interview" class="button">Apply now</a>

Configure API base

Edit web/static/config.js before deploy (or override in your fork):

window.KRAB_API_BASE_URL = "https://krab-interviewer-bot.onrender.com";

When embedding on another origin, keep credentials enabled and set CORS if needed:

KRAB_API_CORS_ALLOWED_ORIGINS=https://yourproject.com,https://www.yourproject.com

Example: Tri State Coverage site

Marketing site links to the funnel; form lives at /interview:

<!-- On tristatecoverage.com careers page --> <p><a href="https://apply.tristatetags.com/requirements">See driver requirements</a></p> <iframe src="https://apply.tristatetags.com/interview" ...></iframe>

Example: Another brand / white-label project

  1. Deploy or reuse the same krab-interviewer-bot service.
  2. Set KRAB_PUBLIC_BASE_URL to that service URL.
  3. On your site, iframe {SERVICE_URL}/interview only.
  4. Add your own hero copy above the iframe; keep requirements link pointing to /requirements.
